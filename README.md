## 🚀 CÓMO USAR

### **OPCIÓN 1: SCRIPT BATCH (MÁS FÁCIL)**

1. **Descarga todo el proyecto**
   ```bash
   git clone https://github.com/aduken666/system-optimizer.git
   cd system-optimizer
   ```

2. **Click derecho en `TURBO.bat`**

3. **Selecciona "Ejecutar como administrador"**

4. **Espera 5-10 minutos** (depende del PC)

5. **Reporte en tu Escritorio**

---

### **OPCIÓN 2: LÍNEA DE COMANDOS**

```batch
cd D:\Descargas\system-optimizer
python turbo_optimizer.py
```

(Ejecuta como administrador para máxima optimización)

---

### **OPCIÓN 3: COMPILADO A .EXE**

```batch
pyinstaller --onefile --windowed --icon=icon.ico turbo_optimizer.py
```

El `.exe` estará en `dist\`

## 🆘 PROBLEMAS COMUNES

### **"No se ejecuta el .bat"**
→ Haz click derecho → "Ejecutar como administrador"

### **"Python no se reconoce"**
→ Descarga Python: https://www.python.org/downloads/
→ Marca "Add Python to PATH"

### **"Errores de permisos"**
→ Abre CMD como administrador
→ Ejecuta el script nuevamente

### **"El sistema no mejora"**
→ Reinicia el PC (IMPORTANTE)
→ Ejecuta como administrador
