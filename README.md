# Sistema de Diagnóstico y Optimización

Herramienta ejecutable para diagnosticar y optimizar tu PC Windows.

## 📥 Descargar

**[Descarga el .EXE aquí](https://github.com/aduken666/system-optimizer/releases)**

## 🚀 Cómo usar

1. **Descarga** `DiagnosticoOptimizador.exe` desde Releases
2. **Ejecuta como administrador** (click derecho → Ejecutar como administrador)
3. **Espera a que termine** (tarda 2-5 minutos)
4. **Abre el reporte** en tu Escritorio

## ✅ Qué hace

- Diagnóstico completo del sistema
- Análisis de RAM, disco, CPU
- Lista de procesos pesados
- Limpieza de archivos temporales
- Optimización automática
- Genera reporte detallado

## 📋 Requisitos

- Windows 10 o superior
- Permisos de administrador
- 50 MB de espacio libre

## 📊 Salida

El programa genera un archivo `Diagnostico_FECHA_HORA.txt` en tu Escritorio con:
- Estado del sistema
- Uso de recursos
- Procesos activos
- Optimizaciones realizadas
